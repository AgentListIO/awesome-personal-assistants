# Contributing

This list is maintained alongside [agentlist.io](https://www.agentlist.io). Cataloged platforms and services link to spec sheets; ecosystem projects link directly to their source.

## Add or update an entry

- **Platform or service:** [open an issue here](https://github.com/AgentListIO/awesome-personal-assistants/issues/new) with the project’s name, official URL, proposed change, and a primary source. Maintainers update the catalog and its spec link when applicable.
- **Ecosystem project** (skill, fork, companion app, or hosting adaptation): submit a pull request to this repository. Use one line per entry: `- [Name](url) - description.` Include a stars shield for GitHub repositories.

## Ground rules

- Entries are editorial records, not endorsements or paid placements.
- Link the project’s own repository or site; no affiliate or tracking links.
- Support factual claims with primary sources.
- Keep caution flags until evidence supports changing them.
- Abandoned projects are removed when the list retires them.
