# Contributing

This list is maintained alongside the catalog that powers
[agentlist.io](https://agentlist.io). Personal-assistant platforms, memory
layers, and agent services live in the catalog itself — `data/catalog-seed.json`
+ `data/catalog-content.json` in
[arach/agentlist.io](https://github.com/arach/agentlist.io). Ecosystem projects
(skills, forks, companions, hosters) live only in this README.

## To add or update an entry

- **Platform or service** — open an issue or PR on
  [arach/agentlist.io](https://github.com/arach/agentlist.io) with the vendor
  name, homepage, and category; the `spec` link appears here on the next pass.
- **Ecosystem project** (skill, fork, companion app, hosting adaptation) — PR
  this repo directly. One line per entry: `- [Name](url) - description.` plus a
  stars shield if it's a GitHub repo.

## Ground rules

- Entries are editorial records, not endorsements or paid placements.
- Link the project's own repo or site — no affiliate or tracking links.
- `(caution)` flags mark projects whose security story is still settling; keep
  the flag honest rather than removing it.
- Abandoned projects are removed on the refresh that retires them.
